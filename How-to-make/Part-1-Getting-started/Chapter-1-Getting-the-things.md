# Chapter 1: Getting the things

## What you need
You need these:
* [Visual Studio Code](https://code.visualstudio.com/download?_exp_download=d53503e735)
* [GitHub Desktop](https://desktop.github.com/download/)
* [Git](https://git-scm.com/install/windows)

So let's see what do we need them for!

### Visual Studio Code
This is the most important. This is where you program.
#### Features
* Feature 1: Built-in Explorer
* Feature 2: Search
* Feature 3: Commiting
* Feature 4: Run & Debug (needs a launch.json for that)
* Feature 5: Extensions

### GitHub Desktop
This is very important for VSCode. This has one of the most important features: cloning.
#### What does cloning do?
Cloning makes a copy of your GitHub Repo on your desktop. Usually, in the "Documents" folder, of course, if you have Microsoft Windows. I don't own a Mac, or a Linux so I don't know about them.
#### How to clone?
Open GitHub Desktop. Click Add then Clone Repo.
#### Features
* Feature 1: Cloning
* Feature 2: Commiting
* Feature 3: Making Repos

### Git Bash
This is the place where you actually commit.
#### Features
* Feature 1: Turning anything into a Repo. Even your own computer.
* Feature 2: Commiting
* Feature 3: Making files/folders
* Feature 4: Making branches
