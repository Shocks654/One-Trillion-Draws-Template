# Chapter 2: Signing in to apps
## VSCode
* Step 1: Go to the activity bar, and click "Accounts"
* Step 2: Sign in with Microsoft Azure or with GitHub
* Step 3: A website will open. Let VSCode sign in.
## GitHub Desktop
If you are new to GitHub you can make an Account.
* Step 1: First time launch. It gives an option to sign in with GitHub com.
* Step 2: Click on GitHub com. Then Continue with Browser.
* Step 3: Sign in.
## Git Bash
git config --global user.name "GitHub Username"
git config --global user.email "your@email.com"
